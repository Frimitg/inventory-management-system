# راهنمای اجرا

## مرحله ۱: نصب پکیج‌ها
داخل ترمینال VS Code (نه بیرون از پوشه پروژه):
```
npm install
```

## مرحله ۲: اجرای پروژه
```
npm run dev
```
یه لینک مثل `http://localhost:5173` نشون داده می‌شه؛ روش کلیک کن یا توی مرورگر بازش کن.

## ساختار فایل‌ها
```
src/
  theme.js              رنگ‌ها و تابع فرمت عدد
  data/mockData.js       دیتای نمونه (محصولات، دسته‌بندی، تأمین‌کننده، فروش)
  components/            بخش‌های مشترک (Card، Badge، PageHeader، Sidebar)
  pages/                 چهار صفحه‌ی اصلی (Dashboard، Products، Categories، Suppliers)
  App.jsx                فایل اصلی که سایدبار و صفحات رو کنار هم می‌چینه
```

## نکته مهم
ناوبری بین صفحات فعلاً با `useState` داخل `App.jsx` انجام می‌شه، نه روتینگ واقعی.
یعنی هر صفحه URL جدا نداره. اگه بعداً خواستی هر صفحه آدرس مجزا داشته باشه
(مثلاً `/products`)، باید `react-router-dom` رو نصب و جایگزین این منطق کنی.

دیتای داخل `mockData.js` فرضیه؛ باید بعداً از API بک‌اند خودت بیاد.
